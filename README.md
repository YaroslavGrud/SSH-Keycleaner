# 🔐 SSH Key Cleaner

**Полная очистка системы от SSH-ключей и следов аутентификации**  
*Безопасно, детально, с сохранением отчёта*

## 📌 Описание

Скрипт **полностью удаляет** все приватные и публичные SSH-ключи, а также служебные файлы (`known_hosts`, `authorized_keys`, `config`, `*.ppk`) со **всех внутренних дисков** компьютера.  
При этом **съёмные носители (флешки, USB-диски) не сканируются и не повреждаются**.  

Скрипт также останавливает и отключает `ssh-agent`, очищает историю команд PowerShell/CMD и временные файлы, а после работы предлагает перезагрузить систему для окончательной очистки памяти и файла подкачки.

## ✨ Особенности

- ✅ **Безопасность** – проверка содержимого `.pub` файлов (не трогает документы Microsoft Publisher)
- ✅ **Глубокое сканирование** – все внутренние диски, папки `.ssh` пользователей, `ProgramData\ssh`
- ✅ **Режим `-WhatIf`** – предварительный просмотр без удаления
- ✅ **Подробный лог** – автоматически сохраняется в папке запуска
- ✅ **Полная очистка** – ключи, конфиги, агент, история, временные файлы
- ✅ **Игнорирование флешек** – съёмные диски (`DriveType = 2`) не сканируются

## 🚀 Быстрый старт

### Подготовка

- **Вставьте флешку** (если на ней есть ключи, которые нужно сохранить) – скрипт её не тронет.
- Скопируйте `SSH_Keycleaner.ps1` на компьютер (например, в папку `Downloads`).
- **Извлеките флешку** (для полной уверенности, хотя скрипт её и так игнорирует).
- Запустите **PowerShell от имени администратора**.

### Запуск

```powershell
cd C:\Users\%USERNAME%\Downloads   # замените на путь к папке со скриптом
Unblock-File .\SSH_Keycleaner.ps1
.\SSH_Keycleaner.ps1
```
> [!TIP]
> Вместо `%USERNAME%` подставится имя текущего пользователя, или вы можете вручную указать полный путь.

### Параметры

| Параметр | Описание |
|----------|----------|
| `-WhatIf` | Показать, какие файлы будут удалены (без реального удаления) |
| `-AutoConfirm` | Удалить всё без интерактивного подтверждения |
| `-LogPath "путь"` | Указать свой путь для лога (по умолчанию – папка запуска) |

**Примеры:**

```powershell
# Тестовый прогон (ничего не удаляется)
.\SSH_Keycleaner.ps1 -WhatIf

# Полная автоматическая очистка
.\SSH_Keycleaner.ps1 -AutoConfirm
```

### После очистки

- Скрипт предложит **перезагрузить компьютер** – это важно для очистки файла подкачки и кэша памяти.
- Проверьте, что без флешки подключение к серверу **стало невозможным**:
  ```powershell
  ssh user@server_ip
  # Должно быть: Permission denied (publickey)
  ```
- Вставьте флешку и убедитесь, что ваш ключ работает (например, с помощью `ssh -i` или вашего обычного способа подключения).

## ⚙️ Принцип работы

1. **Определение внутренних дисков** – сканируются только `DriveType = 3` (фиксированные диски), съёмные (`DriveType = 2`) игнорируются.
2. **Белый список путей**:
   - Корни внутренних дисков (только файлы в корне, без рекурсии)
   - `C:\ProgramData\ssh` (рекурсивно)
   - Папки `.ssh` всех пользователей (рекурсивно)
3. **Фильтрация файлов**:
   - `.pub` – удаляется, только если первая строка начинается с `ssh-rsa`, `ssh-ed25519` и т.п. (иначе пропускается)
   - `config` / `ssh_config` / `sshd_config` – удаляется, если содержит строки `Host`, `IdentityFile`, `Port` и др.
   - Приватные ключи (`id_*`, `*.ppk`) и служебные файлы (`known_hosts`, `authorized_keys`) удаляются без дополнительной проверки (они обычно лежат только в `.ssh`)
4. **Очистка**:
   - Остановка и отключение службы `ssh-agent`
   - Удаление истории PowerShell и CMD
   - Удаление временных папок `ssh_*` и файлов `*.key` из `%TEMP%`
5. **Логирование** – все действия записываются в файл с меткой времени.

## 📋 Требования

- Windows 10 / 11 (PowerShell 5.1 или выше, встроенный)
- **Права администратора** (для остановки службы `ssh-agent` и доступа к системным папкам)
